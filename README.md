# manage-team-sy

파견직 근무 관리 대시보드.

## 바로가기

🔗 [https://electron-s.github.io/manage-team-sy/](https://electron-s.github.io/manage-team-sy/)

## 사용 방법

- **팀원:** 위 링크에서 조회만 가능
- **관리자:** 우측 상단 🔒 클릭 → 비밀번호 입력 → 셀 편집 후 ☁ GitHub 저장

## 기술 스택

- 단일 HTML 파일 (`index.html`)
- 데이터 파일 (`data.json`) — GitHub API로 직접 저장
- GitHub Pages로 호스팅
